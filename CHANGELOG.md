# Changelog


## [1.2.0] - 2026-11-10

### Added
- Rename product to **ZenaEML Viewer to PDF**
- Convert open `.eml` / `.msg` to PDF (headers, body, attachment list; inline images embedded)
- Menu: **Save email PDF…** (⌘P) and **Save invoice PDF…** for FatturaPA XML
- Detect Italian FatturaPA (`FatturaElettronica`) XML inside nested PEC / `.eml` trees; append to email PDF or save separately
- English / Italian UI + PDF labels (System, English, or Italian)
- Welcome screen: short what-it-does / how-it-works copy

## [1.1.0] - 2026-10-27

### Added

- Finder Quick Look preview for `.eml` / `.emlx` / `.msg`
- Nested `message/rfc822` support (PEC forwards / email-in-email)
- Open nested `.eml` attachments in the same window

### Changed

- Product branding: **ZenaEML Viewer** by ZenaConsult
- App icon: original envelope mark with ZenaConsult badge on a transparent background

## [1.0.0] - 2026-04-16

### Added

- Initial `.eml` and `.msg` viewer for macOS
